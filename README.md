# 字幕校稿对齐（Subtitle Proofreading Aligner）

把**逐行对白稿**与 **SRT 字幕**自动对位的 Web 小工具：解析并保留 SRT 时间码，
对两侧文本做去空白/去标点的归一化，以**归一化字符编辑距离**为匹配代价、
**跳过任一条计 0.45**，求**全局单调、最低代价**的对齐。两侧条目各最多匹配一次、
允许缺项；重复短句也严格按整段顺序匹配。可填写**人工锚点**把确定对应的
「行:块」强制配对，锚点之间仍自动对齐。页面并排显示对位/缺项/锚点行与时间码，
可一键下载含全部状态的 CSV。

另内置 **SRT 时间轴重定时**工具：输入原 SRT 与若干「原时间 → 目标时间」校准点，
按**分段线性映射**整体重排时间轴（区间外按最近区段斜率外推，单点时整体平移），
页面预览原/新时间码，可下载保留字幕正文并重新编号的 SRT。

还内置 **SRT 断行排版**工具：粘贴 SRT 并设置每行最大显示宽度（12～60），
逐块把正文排成**最多两行**——东亚宽字符计 2、其余计 1，组合字符不与前字拆开、
连续拉丁单词不拆分；枚举全部合法断点，按**句末标点优先、两行宽度均衡**选优
（非固定字数贪心），无合法排法的块保留原正文并标记人工处理。预览原文/结果/状态，
下载的 SRT **保持原时间码与文字内容，仅调整换行**。

另有 **SRT 时间避让**工具：输入 SRT、最小块间隔与单块最大平移量，整体平移修整
**重叠或间隔过短**的相邻字幕块——保持每块**时长、顺序与正文**不变，在非负时间与
平移上限内，先求**全段最大绝对平移量最小**的可行时间轴，平移量相同时再让各块
**按原入点就近**落位（整体求解，不做逐块贪心，避免把冲突推给后面的块）。
页面预览原/新时间码与各块平移量；约束无法满足时**指出首个冲突块并禁止导出**，
可行时可下载修整后的 SRT。

还有 **双语 SRT 拆轨**工具：输入每块恰好两行（一行中文、一行英文）的双语 SRT，
按**错配计分**（汉字落在英文轨、拉丁字母落在中文轨各计 1 分，相邻块中英行
上下顺序变化另计 2 分）以**全段最小总代价**的动态规划确定每块归属，平局逐块
优先「中文在上」。页面并排预览两轨归属与总错配分，可分别下载**保留原时间码与
正文行内容、从 1 重编号**的中文轨 / 英文轨 SRT；正文行数不符的块会指出块号并
拒绝导出。

另有 **双语术语核对** 工具：输入每块恰好两行的双语 SRT 与逐行
「英文术语<TAB>指定中文译法」词表，复用拆轨逻辑分出中文轨/英文轨；英文轨仅跨
**相邻且间隔 0～500 毫秒**的块拼接成段，归一化（大小写折叠、全角转半角、
空白折叠）后按**英文词边界**查找术语；重叠候选先选**覆盖字符最多**者、再按
出现位置与词表顺序，**同一英文字符只归属一次**。命中覆盖的块，其中文轨
**去空白后包含指定译法**即合格，否则标出块号、英文原文与应译词。页面预览
合格/缺译结果并可下载 UTF-8 CSV；词表空项、重复英文术语或非双行块都会
**指出位置并清空旧结果**。

另有 **SRT 版本差异审校**工具：输入旧版与新版 SRT，按块序做**全局最小代价**
对齐，允许 1:1、1:2（拆分）、2:1（合并）与单侧缺项（增删）；候选先合并正文
再做同样的文本归一化，以归一化编辑距离计分，拆并另加 0.1、增删各计 0.45，
总分相同时优先入出点偏差更小、再优先 1:1。结果标出**未变 / 新增 / 删除 /
仅改时 / 文字改动 / 拆分 / 合并**，并排显示两侧时间码与正文，可下载 UTF-8 CSV。

另有 **剪辑字幕重建**工具：输入原 SRT 与 JSON 剪辑数组（每项含非负整数毫秒
`source_in`、`source_out`、`target_in`，出点须大于入点），片段可**乱序、重复**，
输出区间可**重叠**，按**原速**把每段素材区间内的字幕**裁切后平移**到目标位置
（左闭右开求交，空交集丢弃）。按映射后全部端点切分时间轴，每段把当前有效的
原字幕块按**解析序位**排列、保留各块正文换行并以换行连接；同一原块被多段剪辑
覆盖时**只显示一次**，直到最后一份覆盖结束才移除。仅合并相邻且有效原块集合
相同的区间、跳过无字幕区间，导出按时间**从 1 编号的无重叠 SRT**。页面预览
重建后时间码、原块序位与正文；非法剪辑清单**指出项号并禁止导出**。

另有 **字幕阅读负载审查**工具：输入 SRT 与整数**阅读速度**（每秒 4～30 个
显示宽度单位），正文**去掉空白**后按**东亚宽字符计 2、其余字符计 1**，
每块所需阅读毫秒数**向上取整**；阅读只允许发生在块自身 **[入点, 出点)**
区间内。所有块放在**同一阅读时间轴**上，**同一时刻只读一块**，按
**最早出点优先**分配、同出点按**解析序位**，在某块入点、出点或当前块
读完时重新挑选（后放行但出点更早的块可抢占）。块到出点仍未读完即标为
**逾期**并记录**未分配毫秒数**。页面按时间预览块号、所需/已分配时长与
合格/逾期，汇总逾期数并可下载 UTF-8 CSV；**入点不早于出点**的块会
**指出块号并清空旧结果**。

另有 **字幕分卷**工具：输入最多 **200 块** SRT、份数 **K（1～20）**与
每卷**最短 / 目标 / 最长时长**（正整数毫秒，最短 ≤ 目标 ≤ 最长）。全部块
按**入点、解析序位**排序后，把**直接或传递重叠**（区间左闭右开，端点相触
不算重叠）的块合并为不可拆开的重叠组，只在**相邻无重叠组之间**切分，
所有块恰好分入 **K 个非空连续卷**；卷时长为**最晚出点 − 最早入点**。
以动态规划全局最小化各卷**（时长 − 目标）² 之和**，总分相同时取
**切分处下一卷入点序列字典序最小**（切点尽量靠前）的方案。预览各卷
原起止时间、块数、时长与总分，可一键下载 ZIP（`volume01.srt`……各卷
时间码**减去本卷最早入点**、保留正文并从 1 编号）；**无解**或存在
**非正时长块**时报错、**清空旧结果并禁用下载**。

后端 Python + FastAPI，前端原生 HTML / CSS / JavaScript（无框架、无构建步骤）。

## 一键启动（推荐：Docker Compose）

需要本机已安装 Docker 与 Docker Compose（`docker compose version` 可用）。

```bash
docker compose up -d --build
```

启动后在浏览器打开：

```
http://localhost:8000
```

停止：

```bash
docker compose down
```

### 修改端口

默认占用宿主机 **8000** 端口。改为其它端口有两种方式：

```bash
# 方式一：环境变量临时覆盖
APP_PORT=9000 docker compose up -d --build

# 方式二：复制 .env.example 为 .env 后修改 APP_PORT
cp .env.example .env
# 编辑 .env：APP_PORT=9000
docker compose up -d --build
```

容器内固定监听 8000，仅宿主机映射端口可改（`docker-compose.yml` 中
`"${APP_PORT:-8000}:8000"` 冒号左侧）。

需要 Python 3.11+。


打开 http://localhost:8000 。

## 使用方法

1. 左侧文本框粘贴**逐行对白稿**（每行一句，空行忽略）。
2. 右侧文本框粘贴标准 **SRT**（`序号 / 时间码入点 --> 出点 / 字幕文本`，块间空行分隔）。
3. 可调整「跳过单条代价」（默认 **0.45**，范围 0~1）。
4. （可选）在「**人工锚点**」框填写若干 `行:块` 强制配对，详见
   [下一节](#人工锚点强制配对)。
5. 点 **开始对齐**，下方并排展示结果表：
   - **对位**（绿）：对白稿行与字幕行成功匹配，显示逐行匹配代价；
   - **缺对白稿**（红）：SRT 有该字幕、对白稿缺这一条；
   - **缺字幕**（黄）：对白稿有这句、SRT 中缺失；
   - **锚点**（紫色徽标/底色）：人工指定的强制配对行。
   - 每行都带有对白稿行号、SRT 序号与保留下来的**入点/出点时间码**。
6. 点 **下载 CSV** 导出含状态、代价、行号、文本、时间码的结果（UTF-8 带 BOM，
   Excel 直接打开不乱码）；提供锚点时 CSV 末尾增加「锚点」列标出锚点行。

页面右上/输入框标题旁的「填入示例」可快速体验，其中特意包含缺项与重复短句。

## SRT 时间轴重定时

页面顶部切换到「**SRT 时间轴重定时**」选项卡，可按校准点整体重排字幕时间轴：

1. 左侧文本框粘贴**原 SRT**（与对齐工具同一解析器，保留时间码与正文）。
2. 右侧文本框按顺序填写**校准点**，每行一个：`原时间 --> 目标时间`
   （也接受空白分隔），例如：

   ```
   00:00:01,000 --> 00:00:02,000
   00:00:07,000 --> 00:00:10,500
   ```

   - 时间码格式 `HH:MM:SS,mmm`（毫秒可省略，分隔符 `,` / `.` 均可）；
   - **两列时间都必须严格递增**（原时间列、目标时间列各自递增），
     否则返回 400 并指出第几个校准点；
   - 至少一个校准点，最多 500 个。
3. 点 **开始重定时**，下方表格逐块预览：新编号、原序号、原时间码、
   **新时间码**与字幕文本。
4. 点 **下载 SRT** 导出重定时后的字幕：**保留字幕正文**（含多行原文），
   序号从 1 **重新编号**。

### 映射规则

- 相邻校准点之间，对每个字幕块的**入点、出点**分别做**分段线性映射**
  （区间内线性插值，校准点处精确命中目标时间）；
- 首/末校准点之外，**沿用最近区段的斜率外推**；
- **只有一个校准点时整体平移**（所有时间加上 目标 − 原 的固定偏移）；
- 所有结果统一**取整到毫秒**（四舍五入）。

### 导出前校验（拒绝导出）

映射完成后逐块检查，任一不满足即返回 **400**、指出**具体块号**并拒绝导出：

- **负时间**：映射后入点/出点小于 0（常见于首校准点之前外推过多）；
- **入点不早于出点**：映射后入点 ≥ 出点（如时长被压缩到 0）；
- **字幕入点顺序倒退**：某块入点早于前一块入点（原 SRT 顺序错乱时也会触发）。

错误信息示例：`重定时结果校验失败：第 1 块映射后出现负时间（-00:00:00,300 --> -00:00:00,100）`。

## SRT 断行排版

页面顶部切换到「**SRT 断行排版**」选项卡，可在不改动时间码与文字的前提下，
为每个字幕块重新安排正文换行：

1. 文本框粘贴标准 **SRT**（与对齐/重定时同一解析器，保留序号与时间码）。
2. 设置「**每行最大显示宽度**」（整数，范围 **12～60**，默认 30）。
3. 点 **开始排版**，下方表格逐块预览：**状态**、序号、时间码、**原文**与
   **排版结果**（结果中的换行位置以 ↵ 标出）。
4. 点 **下载 SRT** 导出：**原序号、入点/出点时间码与文字内容全部保持不变，
   只有正文里的换行位置可能变化**。

汇总区分别统计：**单行**（整段一行放得下，保持一行）、**两行**（已重新断行）、
**需人工处理**（无合法排法、保留原正文）。

### 排版规则

- 每个字幕块正文排成**最多两行**；整段一行能放下时保持一行。
- **显示宽度**：东亚宽字符（East Asian Width W/F，如中日韩文字、全角标点）
  计 **2**，其余字符计 **1**；**组合字符**（Unicode 类别 M，如重音符）计 0，
  且**必须附着在前字之后，不可拆开**。
- **连续拉丁字母构成的单词不可拆分**：连续的拉丁/希腊/西里尔字母与数字视作
  一个词，撇号连接的 `don't`、`l'amour` 同样作为整体。
- **合法断点**只有两类：① 空白处（断行后该处空白折叠丢弃）；
  ② 两个相邻词组之间（如中日韩字之间、字与词之间）。
- **枚举全部合法断点**，过滤掉任一行超出宽度上限的排法，再综合
  **句末标点优先**（句末 `。！？….!?` 及其闭合引号 > 句中 `，、；：` 等 >
  无标点）与**两行宽度均衡**（宽度差最小，平局时首行更满）选择最优排法；
  **不做固定字数贪心截断**。
- **无合法两行排法**（如单词本身超过整行宽度，或两行都无法容纳）的块：
  **保留原正文不动**并标记「**需人工处理**」，结果表给出具体原因，
  导出 SRT 时这些块也原样输出。
- 原块内多行正文会先还原为整句再排版（窄体字母/数字跨原行相接时补一个空格，
  中日韩文字直接相接），文字内容不增删。

示例（每行宽度上限 30）：

```
你好，世界！今天我们来聊聊字幕断行排版。
        ↓
你好，世界！
今天我们来聊聊字幕断行排版。
```

## SRT 时间避让

页面顶部切换到「**SRT 时间避让**」选项卡，可整体平移修整重叠或间隔过短的
相邻字幕块：

1. 文本框粘贴标准 **SRT**（与其它工具同一解析器，保留序号、时间码与正文）。
2. 设置「**最小块间隔**」（整数毫秒，**0～60000**，默认 0：相邻块出点到
   下一块入点的最小距离）与「**单块最大平移量**」（整数毫秒，
   **0～3600000**，默认 2000：每块入点允许移动的最大绝对距离）。
3. 点 **开始避让**，下方表格逐块预览：新编号、原序号、**原时间码**、
   **新时间码**、**平移量**（正为后移、负为前移）与字幕文本；
   被平移的块以底色标出。
4. 点 **下载 SRT** 导出修整后的字幕：**保留字幕正文**（含多行原文），
   序号从 1 **重新编号**。

### 避让规则

- 每块**时长、顺序与正文不变**，仅整体平移；新入点不为负。
- 修整后相邻块间隔（上块出点 → 下块入点）≥ 最小块间隔。
- 每块 |平移量| ≤ 单块最大平移量。
- 在上述约束下**全段整体求解**（非逐块贪心，避免把冲突推给后面的块）：
  1. 先使**全段最大绝对平移量最小**（二分平移量 + 前向最早可行判定）；
  2. 最大平移量相同的可行时间轴中，取**各块平移量绝对值之和最小**者——
     即每块按原入点就近落位（化为带单调盒约束的 L1 保序回归精确求解）。
- **时长非正**（入点不早于出点）的块无法仅通过平移修整，直接报错指出块号。
- 约束无法满足（平移上限内不存在可行时间轴）时，返回 **400** 并指出
  **首个冲突块**（前向最早可行入点首次超出其平移上限的块），
  预览与导出同样被拒绝。

错误信息示例：`时间避让失败：第 2 块无法排入时间轴：为满足与前一块的最小间隔，其入点最早为 00:00:00,500，已超出平移上限允许的最晚入点 00:00:00,200（原入点 00:00:00,100，单块最大平移量 100 毫秒）。请增大单块最大平移量或减小最小块间隔`

## 双语 SRT 拆轨

启动后浏览器打开 **http://localhost:8000**（Docker Compose 一键启动见上文，
端口可改），页面顶部切换到「**双语 SRT 拆轨**」选项卡，可把每块恰好两行的
双语字幕（一行中文、一行英文）拆成两条独立字幕轨：

1. 文本框粘贴标准 **SRT**（与其它工具同一解析器，保留序号、时间码与正文行），
   **每个字幕块正文必须恰好两行**。
2. 点 **开始拆轨**，下方表格逐块并排预览：新编号、原序号、时间码、
   **轨序**（中文在上 / 英文在上，轨序与上一块不同的带 ⇄+2 标记）、
   **中文轨**与**英文轨**各自分得的正文行，以及本块错配字符数。
3. 汇总区显示：字幕块数、**错配字符**总数、**顺序变化**次数与**总错配分**。
4. 点 **下载中文轨 SRT** / **下载英文轨 SRT** 分别导出两轨：**保留原时间码与
   正文行内容**，序号从 1 **重新编号**。

### 拆轨规则

- 每块的两行分别归入中文轨与英文轨，归属只有两种：**中文在上**（上行入中文轨）
  或**英文在上**（上行入英文轨）。
- **错配计分**：汉字落在英文轨、拉丁字母落在中文轨，**每个字符各计 1 分**
  （全角拉丁字母同样计为拉丁字母；希腊/西里尔字母不算）；数字、标点等
  中性字符不计分。
- 相邻两块的中英行**上下顺序发生变化，另计 2 分**。
- 每块归属由**全段总代价最小**的动态规划确定（非逐块贪心）：先求各块两种
  归属的错配，再在整段上最小化「错配字符 + 顺序变化 × 2」。
- 总代价相同的方案中，**从第 1 块起逐块优先「中文在上」**——纯数字/标点等
  中性行因此依邻块保持轨序稳定，不会无意义地来回翻转。
- **正文行数不符**（不是恰好两行）的块：返回 **400** 并**指出块号**
  （声明序号与顺序不一致时一并给出），预览与导出同样被拒绝。

错误信息示例：`拆轨失败：第 2 块正文须恰好两行（实际 1 行），无法拆轨`

## 双语术语核对

页面顶部切换到「**双语术语核对**」选项卡，可核对双语字幕中的英文术语是否
使用了指定中文译法：

1. 左侧文本框粘贴**双语 SRT**（每块正文须恰好两行：一行中文、一行英文，
   与双语拆轨同一解析与归属逻辑）。
2. 右侧文本框粘贴**术语词表**，每行一条：`英文术语<TAB>指定中文译法`
   （英文术语与译法之间是一个制表符；空白行忽略，最多 2000 条）。
3. 点 **开始核对**，下方表格逐条预览：**状态**（合格 / 缺译）、块号、
   原序号、时间码、英文轨、中文轨、英文术语与应译词；汇总区显示
   合格/缺译条数、命中次数、字幕块数、英文轨拼接段数与词表术语数。
4. 点 **下载 CSV** 导出全部结果（UTF-8 带 BOM，Excel 直接打开不乱码）。

### 核对规则

- **英文轨拼接**：仅跨**相邻且间隔 0～500 毫秒**的块拼接（块间补一个空格），
  在拼接段内查找术语；间隔超出范围（含重叠块）各自成段，**不跨段匹配**。
- **归一化**：匹配前对英文轨与词表术语做同样处理——NFKC（全角→半角）→
  小写折叠 → 连续空白折叠为单个空格。
- **词边界**：命中两侧不允许是英文字母或数字（如 `AI` 不会匹配 `SAID`
  中的 `ai`，`mp` 不会匹配 `mp4`）。
- **重叠消解**：候选先选**覆盖字符最多**者，再按**出现位置**、**词表顺序**；
  **同一英文字符只归属一次**（被较长命中占用后，与其重叠的更短候选丢弃）。
- **中文核对**：命中覆盖的每个块，其**中文轨去空白后包含指定译法**（同样
  去空白）即**合格**，否则为**缺译**，标出块号、英文原文与应译词；
  一次命中跨多个块时每块各记一条、分别核对。
- **词表校验**：缺 TAB、英文术语或指定译法为空的**空项**，以及归一化后
  **重复的英文术语**，都返回 400 并**指出行号**；非双行块**指出块号**；
  任何错误都会**清空旧结果**。

错误信息示例：`词表无效：词表第 3 行英文术语「Machine Learning」与第 1 行重复（归一化后相同）`

## SRT 版本差异审校

页面顶部切换到「**SRT 版本差异审校**」选项卡，可比较同一字幕的新旧两版：

1. 左/右文本框分别粘贴**旧版 SRT** 与**新版 SRT**（与其它工具同一解析器，
   保留序号、时间码与正文）。
2. 点 **开始比较**，下方表格按块序展示对齐结果，每行标出七种状态之一：
   **未变**（绿）、**仅改时**（紫）、**文字改动**（黄）、**拆分**（青，
   旧 1 块 → 新 2 块）、**合并**（橙，旧 2 块 → 新 1 块）、**新增**（蓝）、
   **删除**（红）；每行并排显示两侧序号、入点/出点时间码与正文，
   配对行附**入出点偏差**（毫秒）。
3. 点 **下载 CSV** 导出全部结果（UTF-8 带 BOM，Excel 直接打开不乱码）。

### 对齐与计分规则

- 按块序做**全局最小代价**对齐（Needleman–Wunsch 风格 DP），每步可以是
  1:1、1:2（拆分）、2:1（合并）或单侧缺项（增删），两版块序均保持单调、
  每块恰好消费一次。
- 候选**先合并正文再归一化**（与其它工具相同的 NFKC + 小写折叠 +
  去空白/标点），以**归一化编辑距离**计文本分；拆并在文本分外**另加 0.1**，
  增删（单侧缺项）各计 **0.45**。
- 总分相同的方案，优先**入出点偏差**（两侧入点差 + 出点差，毫秒）更小者，
  再优先 **1:1**（拆并次数更少）——即 DP 关键字为
  （总分, 入出点偏差, 拆并次数）的字典序。
- 状态判定：1:1 配对中正文完全一致且时间码一致为**未变**，仅时间码不同为
  **仅改时**，正文不同为**文字改动**；拆分/合并按结构标记
  （即使合并后正文归一化相同）。

## 剪辑字幕重建

页面顶部切换到「**剪辑字幕重建**」选项卡，可按非线性剪辑的素材片段重建字幕时间轴：

1. 左侧文本框粘贴**原 SRT**（与其它工具同一解析器，保留时间码与正文换行）。
2. 右侧文本框填写 **JSON 剪辑数组**，每项为一个素材片段：

   ```json
   [
     {"source_in": 0,    "source_out": 3000, "target_in": 0},
     {"source_in": 3000, "source_out": 6000, "target_in": 2000},
     {"source_in": 0,    "source_out": 3000, "target_in": 1500}
   ]
   ```

   - `source_in` / `source_out` / `target_in` 均为**非负整数毫秒**；
   - **`source_out` 必须大于 `source_in`**（出点大于入点）；
   - 片段**可乱序、可重复**（同一段素材允许被多次使用），输出（目标）区间
     **允许重叠**；非法项返回 400 并**指出是第几项**。
3. 点 **开始重建**，下方表格按时间顺序预览：**新序号、重建后时间码、
   原块序位**（该时段生效的原 SRT 块解析序位）与**正文**（块内换行保留，
   多个原块之间再换行连接）。
4. 点 **下载 SRT** 导出重建结果：按时间**从 1 编号、区间互不重叠**。

### 重建规则

- **原速映射**：素材时间 `s ∈ [source_in, source_out)` 映射到目标时间
  `target_in + (s − source_in)`，不做变速。
- **左闭右开求交**：每个字幕块 `[a,b)` 与每段素材区间 `[si,so)` 取交集
  `[max(a,si), min(b,so))`；**空交集丢弃**（仅端点相触、如 `b == si` 也算空），
  非空交集裁切后整体平移到目标位置。
- **端点切分**：收集所有覆盖块映射后的入/出端点切分目标时间轴；每个切片中
  当前有效的原字幕块按 **SRT 解析序位**（从 1 开始）排列，各块正文保留
  自身换行，块与块之间用 `\n` 连接。
- **覆盖计数去重**：同一原块被多段剪辑覆盖时只显示一次——每段覆盖各计一份，
  重叠处计数叠加，**直到最后一份覆盖结束才移除**；因此覆盖区间重叠/相接处
  不会重复出现同一正文。
- **合并与跳过**：仅合并**相邻且有效原块集合相同**的切片（无字幕空隙会阻断
  合并，不会把字幕铺到没有覆盖的时间段）；**无字幕区间跳过**，不出现在预览
  与导出中。

错误信息示例：`第 2 项 source_out（50 毫秒）须大于 source_in（50 毫秒）`。

## 字幕阅读负载审查

启动后浏览器打开 **http://localhost:8000**（Docker Compose 一键启动见上文，
端口可改），页面顶部切换到「**字幕阅读负载审查**」选项卡，可检查每块字幕
能否在自身显示时段内读完：

1. 文本框粘贴标准 **SRT**（与其它工具同一解析器，保留序号与时间码）。
2. 设置「**阅读速度**」（整数，每秒 **4～30** 个显示宽度单位，默认 10）。
3. 点 **开始审查**，下方表格按**时间顺序**逐块预览：**状态**（合格 /
   逾期）、块号（解析序位）、原声明序号、时间码、**显示宽度**、
   **所需毫秒**、**已分配毫秒**与**未分配毫秒**、正文；逾期行以红底标出。
4. 汇总区显示合格/逾期块数、字幕块数、阅读速度，以及所需/已分配/未分配
   毫秒合计；点 **下载 CSV** 导出全部结果（UTF-8 带 BOM，Excel 直接打开
   不乱码）。

### 审查规则

- **显示宽度**：正文**去掉所有空白**（空格、Tab、换行、全角空格等）后，
  东亚宽字符（East Asian Width W/F，如中日韩文字、全角标点）计 **2**，
  其余字符计 **1**。
- **所需时长**：`所需阅读毫秒 = ceil(显示宽度 × 1000 ÷ 阅读速度)`
  （向上取整，保证给出的毫秒数一定读得完）。
- **阅读窗口**：每块只允许在自身 **[入点, 出点)**（左闭右开）内被阅读；
  到出点尚未读完的部分无法补读，记为**未分配毫秒**（所需 − 已分配），
  该块标记为**逾期**；恰好在出点读完仍算合格。
- **统一时间轴调度**：所有块放在同一条阅读时间轴上，**同一时刻只读一
  块**；按**最早出点优先**（EDF，earliest deadline first）挑选当前可读块，
  出点相同时按 **SRT 解析序位**。每块**入点**（放行可读）、**出点**
  （截止）或**当前块读完**时立即重新挑选——后放行但出点更早的块会
  **抢占**正在读的长块；时间轴空闲时直接跳到下一个入点，不浪费时长。
- **入点不早于出点**（入点 ≥ 出点）的块无法安排阅读：返回 **400** 并
  **指出块号**（声明序号与解析序位不一致时一并给出），预览与导出同样
  被拒绝，页面上的旧结果会被清空。

错误信息示例：`阅读负载审查失败：第 2 块入点不早于出点（00:00:02,000 --> 00:00:02,000），无法安排阅读`

## 字幕分卷

页面顶部切换到「**字幕分卷**」选项卡，可把整段字幕切成 K 个时长受控、
互不拆开重叠块的连续卷：

1. 文本框粘贴标准 **SRT**（与其它工具同一解析器，最多 **200 块**）。
2. 设置份数 **K（1～20）** 与每卷**最短 / 目标 / 最长时长**（正整数毫秒，
   须满足 最短 ≤ 目标 ≤ 最长）。
3. 点 **开始分卷**，下方逐卷预览：**卷号、原入点、原出点、块数、
   时长（毫秒）与本分**；汇总区显示卷数、总块数、时长范围、目标与
   **总分**（各卷 (时长 − 目标)² 之和）。
4. 点 **下载分卷 ZIP** 得到 `subtitle-volumes.zip`，内含
   `volume01.srt`、`volume02.srt`…… 每卷 SRT 的时间码**减去本卷最早
   入点**（每卷都从 00:00:00,000 开始），**正文保留**（含多行原文），
   序号**从 1 重新编号**。

### 分卷规则

- 全部块先按**入点升序、同入点按解析序位**排序，分卷严格沿该序进行。
- 时间区间**左闭右开**：两块只要有时间交集就算重叠（仅端点相触、
  上一块出点 == 下一块入点不算）；**直接或传递重叠**的块合为同一
  **重叠组**，同组块**必须同卷**，切分只允许落在**相邻且互不重叠的
  组之间**。
- 所有块**恰好分入 K 个非空连续卷**；卷时长 = 卷内最晚出点 − 最早
  入点，每卷时长均须在 **[最短时长, 最长时长]** 内。
- 在全部可行切法中**全局最小化总分** `Σ(卷时长 − 目标时长)²`
  （动态规划，非逐卷贪心）；总分相同的方案取**切分处下一卷入点序列**
  （第 2 卷至第 K 卷入点，按卷序）**字典序最小**者，即切点尽量靠前。
- **无解**（重叠组数少于 K，或不存在满足时长区间的 K 段切分）返回
  **400** 并说明原因；**入点不早于出点（非正时长）**的块返回 400 并
  **指出块号**；两种情况下页面都会**清空旧结果并禁用下载**。

错误信息示例：

- `分卷失败：无法分成 5 卷：存在直接或传递重叠的块必须同卷，全部块只能形成 3 个可切分段，少于份数 5`
- `分卷失败：无法把字幕分成 3 卷且每卷时长都在 3000～15000 毫秒之间：不存在满足约束的切分方案`
- `分卷失败：第 2 块入点不早于出点（00:00:02,000 --> 00:00:02,000），时长非正，无法分卷`

## 人工锚点（强制配对）

自动对齐在个别位置不符合预期时，可人工指定若干锚点把确定对应的两行强行配对：

- **输入格式**：`对白稿行序位:SRT块序位`，多对之间用逗号、分号或空格分隔，
  冒号中英文均可，例如 `3:3, 10:8`、`1：1 6：5`。
- **序位定义**：均从 **1** 开始，指**解析后**条目在各自序列中的序位——
  对白稿即非空行的行号，SRT 即字幕块的块序位（与结果表两列 `#` 一致）。
- **校验规则**：每对必须在两侧实际条目范围内；两列序位都必须**严格递增**。
  越界、重复、交叉（一列序位倒退）都会返回 **400** 并给出具体原因
  （如 `锚点无效：第 2 个锚点 (3:2) 与前一锚点 (1:3) 交叉：两列序位必须同时严格递增`）。
- **对齐方式**：首锚点之前、相邻锚点之间、末锚点之后的各段，仍分别按现有的
  最低代价单调对齐；锚点本身作为强制配对行按顺序拼接——**即使两侧文本差异
  很大（代价 1.0）也绝不跳过锚点**。锚点之外的其他条目照常可能显示为
  「缺对白稿 / 缺字幕」。
- **结果标识**：结果表中锚点行带紫色「锚点」徽标与底色，汇总区显示锚点数；
  CSV 导出额外增加「锚点」列，锚点行标记为 `锚点`。
- **未提供锚点时，对齐结果、接口字段与 CSV 表头均与原来完全一致。**

页面与接口均在同一地址：启动后浏览器打开 **http://localhost:8000**
（端口可改，见上文「修改端口」，例如 `APP_PORT=9000 docker compose up -d --build`
后访问 http://localhost:9000 ）。

API 调用时 `/api/align` 与 `/api/export.csv` 均接受可选的 `anchors` 数组：

```bash
curl -s -X POST http://localhost:8000/api/align \
  -H 'Content-Type: application/json' \
  -d '{"script":"第一行\n第二行\n第三行",
       "srt":"1\n00:00:01,000 --> 00:00:02,000\n字幕甲\n\n2\n00:00:03,000 --> 00:00:04,000\n字幕乙\n",
       "anchors":[{"script":1,"srt":2}]}'
```

## 对齐算法说明

对两侧条目序列 `A`（对白稿）、`B`（SRT）做 Needleman–Wunsch 风格的全局序列对齐：

- 文本归一化：Unicode NFKC（全角→半角等）+ 小写折叠（casefold），
  再剔除所有**空白**与**标点**（Unicode 类别 Z / P / C），中日韩文字原样保留。
  因此 `你好，世界！` 与 `你好世界` 视为完全相同（代价 0）。
- 匹配代价：`编辑距离(归一化A, 归一化B) / max(长度A, 长度B)`，范围 0~1。
- 跳过代价：任一条不参与匹配，计固定 **0.45**（可在页面调整）。
- 动态规划在整张 `(n+1)×(m+1)` 表上取全局最小值，保证：
  - **全局单调**：对位顺序与两侧原始顺序一致，不交叉；
  - **每条最多匹配一次**，两侧都允许缺项；
  - 重复短句依据其在整段中的先后顺序依次对位，不会都吸到同一条。

距离矩阵由 rapidfuzz(C++) 批量计算、DP 使用 numpy；缺少 numpy 时自动回退到
纯 Python 实现（结果完全一致，仅速度较慢）。

### 规模与限制

- 每侧最多 **2000 条**（单次请求文本各 2 MB 内）；超出会返回 400 并提示拆分。
  常规影视剧字幕（数百至约一千多条）秒级返回。
- 该工具为本地/内网校稿辅助，默认无需鉴权；如需暴露到公网请自行放在
  反向代理与鉴权之后。

| POST | `/api/termcheck` | 入参 `{"srt","glossary"}`，返回双语术语核对预览 `summary` 与逐条 `rows` |
| POST | `/api/termcheck.csv` | 同入参，直接下载术语核对结果 CSV（UTF-8 带 BOM） |
| POST | `/api/diff` | 入参 `{"old_srt","new_srt"}`，返回版本差异 `summary` 与逐行 `rows` |
| POST | `/api/diff.csv` | 同入参，直接下载差异结果 CSV（UTF-8 带 BOM） |
| POST | `/api/rebuild` | 入参 `{"srt","clips"}`，返回剪辑字幕重建预览 `summary` 与逐条 `rows` |
| POST | `/api/rebuild.srt` | 同入参，直接下载重建后的 SRT（按时间从 1 编号、互不重叠） |
| POST | `/api/reading` | 入参 `{"srt","speed"}`，返回阅读负载审查预览 `summary` 与逐块 `rows` |
| POST | `/api/reading.csv` | 同入参，直接下载阅读负载审查结果 CSV（UTF-8 带 BOM） |
| POST | `/api/volumes` | 入参 `{"srt","k","min_ms","target_ms","max_ms"}`，返回分卷预览 `summary` 与逐卷 `volumes` |
| POST | `/api/volumes.zip` | 同入参，直接下载分卷 ZIP（`volume01.srt`…，各卷时间码减去本卷最早入点、从 1 编号） |

`anchors` 为可选的人工锚点数组：`[{"script": 3, "srt": 3}, {"script": 10, "srt": 8}]`，
元素为解析后 1 起始的「对白稿行序位 / SRT 块序位」，两列须严格递增，
非法锚点返回 400。详见上文「人工锚点（强制配对）」。

`rows` 中每行字段：`status`（`match` / `missing_script` / `missing_srt`）、
`cost`、`script_index`、`script_text`、`srt_index`、`srt_text`、
`start_tc`、`end_tc`；提供锚点时，对位行额外带 `anchor` 布尔字段
（锚点行为 `true`），`summary` 额外带 `anchors` 计数，CSV 增加「锚点」列。

重定时接口 `/api/retime` 与 `/api/retime.srt` 的 `points` 为校准点数组：
`[{"source": "00:00:01,000", "target": "00:00:02,000"}, ...]`，两列时间均须
严格递增；预览 `rows` 每块字段：`new_index`（重新编号）、`index`（原序号）、
`old_start_tc` / `old_end_tc`、`new_start_tc` / `new_end_tc`、`text`。
校验失败（负时间 / 入点不早于出点 / 入点顺序倒退）返回 400 并指出块号。

```bash
curl -s -X POST http://localhost:8000/api/retime \
  -H 'Content-Type: application/json' \
  -d '{"srt":"1\n00:00:01,000 --> 00:00:02,500\n你好，世界！\n",
       "points":[{"source":"00:00:01,000","target":"00:00:02,000"},
                 {"source":"00:00:07,000","target":"00:00:10,500"}]}'
```

断行排版接口 `/api/relayout` 与 `/api/relayout.srt` 的入参为
`{"srt": "...", "max_width": 30}`，`max_width` 为每行最大显示宽度
（整数 **12～60**，越界返回 400）。预览 `rows` 每块字段：`index`、
`start_tc` / `end_tc`、`original_text`（原正文，多行以空格连接）、
`result_text`（排版结果，两行以 `\n` 分隔）、`line_count`、
`status`（`single` / `wrapped` / `manual`）、`reason`（manual 时的
人工处理原因）；`summary` 含 `total`、`max_width`、`single`、`wrapped`、
`manual` 计数。

```bash
curl -s -X POST http://localhost:8000/api/relayout \
  -H 'Content-Type: application/json' \
  -d '{"srt":"1\n00:00:01,000 --> 00:00:03,000\n你好，世界！今天天气真不错。\n",
       "max_width":20}'
```

时间避让接口 `/api/avoid` 与 `/api/avoid.srt` 的入参为
`{"srt": "...", "min_gap_ms": 0, "max_shift_ms": 2000}`（均为整数毫秒，
可省略；`min_gap_ms` 范围 **0～60000**、`max_shift_ms` 范围 **0～3600000**，
越界返回 400）。预览 `rows` 每块字段：`new_index`（重新编号）、
`index`（原序号）、`old_start_tc` / `old_end_tc`、
`new_start_tc` / `new_end_tc`、`shift_ms`（平移量，正为后移、负为前移）、
`text`；`summary` 含 `total`、`min_gap_ms`、`max_shift_ms`、
`max_abs_shift_ms`（实际最大平移量）、`moved`（被平移块数）。
约束无法满足时返回 400 并指出首个冲突块，导出同样被拒绝。

```bash
curl -s -X POST http://localhost:8000/api/avoid \
  -H 'Content-Type: application/json' \
  -d '{"srt":"1\n00:00:01,000 --> 00:00:03,000\n你好，世界！\n\n2\n00:00:02,500 --> 00:00:04,000\n重叠的一块\n",
       "min_gap_ms":0, "max_shift_ms":2000}'
```

双语拆轨接口 `/api/split`、`/api/split.zh.srt` 与 `/api/split.en.srt` 的入参均为
`{"srt": "..."}`（每块正文须恰好两行，否则返回 400 并指出块号）。预览 `rows`
每块字段：`new_index`（重新编号）、`index`（原序号）、`start_tc` / `end_tc`、
`order`（`zh_top` 中文在上 / `en_top` 英文在上）、`zh_line` / `en_line`
（两轨各自分得的正文行原文）、`mismatch`（本块错配字符数）、
`switched`（相对上一块轨序是否变化）；`summary` 含 `total`、`mismatch_chars`
（错配字符总数）、`switches`（顺序变化次数）、`switch_cost`（顺序变化计分，
即次数 × 2）、`total_cost`（总错配分 = 错配字符 + 顺序变化计分）。

```bash
curl -s -X POST http://localhost:8000/api/split \
  -H 'Content-Type: application/json' \
  -d '{"srt":"1\n00:00:01,000 --> 00:00:03,000\n你好，世界！\nHello, world!\n"}'
```

双语术语核对接口 `/api/termcheck` 与 `/api/termcheck.csv` 的入参均为
`{"srt": "...", "glossary": "..."}`：`srt` 为每块恰好两行的双语 SRT，
`glossary` 为逐行「英文术语<TAB>指定中文译法」词表（空白行忽略，最多 2000
条；空项与归一化后重复的英文术语返回 400 并指出行号，非双行块指出块号）。
预览 `rows` 每条字段：`status`（`ok` 合格 / `missing` 缺译）、`block_pos`
（块号，解析序位）、`index`（声明序号）、`start_tc` / `end_tc`、
`en_line` / `zh_line`（该块两轨原文）、`term`（词表英文术语）、`matched`
（归一化英文轨中实际命中的文本）、`expected_zh`（应译词）；`summary` 含
`total_blocks`、`chains`（英文轨拼接段数）、`terms`、`hits`（去重后的命中
次数，一次命中可覆盖多个块）、`ok`、`missing`、`total_rows`。

```bash
curl -s -X POST http://localhost:8000/api/termcheck \
  -H 'Content-Type: application/json' \
  -d '{"srt":"1\n00:00:01,000 --> 00:00:03,000\n机器学习正在改变世界。\nMachine learning is changing the world.\n",
       "glossary":"machine learning\t机器学习"}'
```

版本差异接口 `/api/diff` 与 `/api/diff.csv` 的入参均为
`{"old_srt": "...", "new_srt": "..."}`（两版 SRT 全文）。预览 `rows` 每行字段：
`status`（`unchanged` 未变 / `time_only` 仅改时 / `text_changed` 文字改动 /
`split` 拆分 / `merge` 合并 / `added` 新增 / `deleted` 删除）、`cost`、
`old_index` / `new_index`（两侧序号数组，拆并时两个、缺项时为空）、
`old_start_tc` / `old_end_tc` / `new_start_tc` / `new_end_tc`（成组块的
首入点/末出点）、`old_text` / `new_text`（多块正文以 `\n` 连接）、
`time_dev_ms`（配对行的入出点偏差毫秒，缺项行为 `null`）；`summary` 含七种
状态计数、`total_rows`、`total_cost` 与 `old_blocks` / `new_blocks`。

```bash
curl -s -X POST http://localhost:8000/api/diff \
  -H 'Content-Type: application/json' \
  -d '{"old_srt":"1\n00:00:01,000 --> 00:00:02,000\n你好，世界！\n",
       "new_srt":"1\n00:00:01,500 --> 00:00:02,500\n你好，世界！\n"}'
```

剪辑字幕重建接口 `/api/rebuild` 与 `/api/rebuild.srt` 的入参均为
`{"srt": "...", "clips": [...]}`。`clips` 每项含非负整数毫秒
`source_in`、`source_out`、`target_in`，且 `source_out > source_in`；
片段可乱序、重复，目标区间可重叠。任一项非法（缺字段、非整数、为负、
出点不大于入点、不是对象等）返回 **400** 并指出项号（如 `第 2 项 ...`）。
预览 `rows` 每条字段：`new_index`（按时间从 1 编号）、
`start_tc` / `end_tc`（重建后时间码）、`source_indices`（该条所含原字幕块
的解析序位数组，升序）、`text`（各块正文保留块内换行、块间以 `\n` 连接）；
`summary` 含 `total`（导出条数）、`clips`（剪辑片段数）、
`source_blocks`（实际用到的原块数）。所有片段与字幕均不相交时预览为空、
导出为空 SRT（HTTP 200）。

```bash
curl -s -X POST http://localhost:8000/api/rebuild \
  -H 'Content-Type: application/json' \
  -d '{"srt":"1\n00:00:01,000 --> 00:00:03,000\n你好，世界！\n",
       "clips":[{"source_in":1000,"source_out":3000,"target_in":0}]}'
```

阅读负载审查接口 `/api/reading` 与 `/api/reading.csv` 的入参均为
`{"srt": "...", "speed": 10}`，`speed` 为整数阅读速度（每秒 **4～30** 个
显示宽度单位，省略时取 10；越界或非整数返回 422/400）。预览 `rows` 按
**入点升序**（同入点按出点、解析序位）排列，每块字段：`status`
（`ok` 合格 / `overdue` 逾期）、`pos`（块号，解析序位）、`index`
（声明序号）、`start_tc` / `end_tc`、`width`（去空白后的显示宽度单位数）、
`required_ms`（所需阅读毫秒，向上取整）、`allocated_ms`（在自身
[入点, 出点) 内分配到的毫秒）、`unallocated_ms`（未分配毫秒 = 所需 −
已分配）、`text`（正文）；`summary` 含 `total`、`speed`、`ok`、
`overdue`（逾期块数）与所需/已分配/未分配毫秒合计。入点不早于出点的块
返回 **400** 并指出块号，导出同样被拒绝。

```bash
curl -s -X POST http://localhost:8000/api/reading \
  -H 'Content-Type: application/json' \
  -d '{"srt":"1\n00:00:00,000 --> 00:00:01,000\n你好，世界！\n","speed":10}'
```

字幕分卷接口 `/api/volumes` 与 `/api/volumes.zip` 的入参均为
`{"srt": "...", "k": 3, "min_ms": 1000, "target_ms": 10000, "max_ms": 20000}`：
`srt` 最多 **200 块**；`k` 为份数（整数 **1～20**），`min_ms` /
`target_ms` / `max_ms` 为正整数毫秒且须满足
**min_ms ≤ target_ms ≤ max_ms**（越界返回 422/400）。预览 `volumes`
每卷字段：`number`（卷号，从 1 开始）、`start_tc` / `end_tc`（卷内
最早入点 / 最晚出点的原时间码）、`start_ms` / `end_ms`、
`block_count`（卷内块数）、`duration_ms`（卷时长 = 最晚出点 − 最早
入点）、`target_ms`、`score`（本分 = (时长 − 目标)²）；`summary` 含
`k`、`total_blocks`、`min_ms` / `target_ms` / `max_ms` 与
`total_score`（各卷 score 之和）。重叠组不足 K 份或无满足时长约束的
切法时返回 **400**（无解）；非正时长块返回 400 并指出块号，导出同样
被拒绝。ZIP 内文件名为 `volume01.srt`、`volume02.srt`……

```bash
curl -s -X POST http://localhost:8000/api/volumes \
  -H 'Content-Type: application/json' \
  -d '{"srt":"1\n00:00:00,000 --> 00:00:05,000\n甲\n\n2\n00:00:10,000 --> 00:00:12,000\n乙\n",
       "k":2,"min_ms":1000,"target_ms":5000,"max_ms":20000}'
```

## 项目结构

```
.
├── app/
│   ├── main.py        # FastAPI：/api/align、/api/export.csv、/api/retime(.srt)、/api/relayout(.srt)、/api/avoid(.srt)、/api/split(.zh/.en.srt)、/api/termcheck(.csv)、/api/diff(.csv)、/api/rebuild(.srt)、/api/reading(.csv)、/api/volumes(.zip)、静态页托管
│   ├── alignment.py   # 全局单调对齐 DP（numpy 实现 + 纯 Python 回退）
│   ├── parsers.py     # 逐行对白稿与 SRT 解析（保留时间码与正文行）
│   ├── retime.py      # SRT 时间轴重定时：校准点分段线性映射与导出校验
│   ├── relayout.py    # SRT 断行排版：宽度计量、合法断点枚举与最优选点、SRT 导出
│   ├── avoid.py       # SRT 时间避让：最小最大平移量求解 + 带盒 L1 保序回归就近落位、SRT 导出
│   ├── split.py       # 双语 SRT 拆轨：错配计分、全段最小总代价 DP（平局逐块中文在上）、单轨 SRT 导出
│   ├── termcheck.py   # 双语术语核对：词表解析、英文轨拼接、词边界匹配、重叠消解与中文核对
│   ├── rebuild.py     # 剪辑字幕重建：素材区间裁切平移、覆盖计数去重、端点切分/同集合合并、SRT 导出
│   ├── reading.py     # 字幕阅读负载审查：显示宽度计量 + 同一阅读时间轴上的最早出点优先（EDF）事件模拟
│   ├── volumes.py     # 字幕分卷：直接/传递重叠组合并 + K 卷时长约束 DP（平局切分入点字典序最小）、各卷减本卷入点的 ZIP 导出
│   ├── diffalign.py   # SRT 版本差异：1:1/1:2/2:1/缺项全局最小代价 DP（字典序键：总分→入出点偏差→拆并次数）
│   └── textnorm.py    # 归一化与归一化字符编辑距离
├── static/
│   ├── index.html     # 页面结构（对齐 / 重定时 / 断行排版 / 时间避让 / 双语拆轨 / 术语核对 / 版本差异 / 剪辑重建 / 阅读负载审查 / 字幕分卷十个选项卡）
│   ├── style.css
│   ├── app.js         # 对齐页面前端交互（fetch 调接口、渲染、下载）
│   ├── retime.js      # 重定时页面前端交互（含各页签切换）
│   ├── relayout.js    # 断行排版页面前端交互
│   ├── avoid.js       # 时间避让页面前端交互
│   ├── split.js       # 双语拆轨页面前端交互
│   ├── termcheck.js   # 双语术语核对页面前端交互
│   ├── diff.js        # 版本差异审校页面前端交互
│   ├── rebuild.js     # 剪辑字幕重建页面前端交互
│   ├── reading.js     # 字幕阅读负载审查页面前端交互
│   └── volumes.js     # 字幕分卷页面前端交互
```
